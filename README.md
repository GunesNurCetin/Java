# ☕ Java Projeleri Arşivi

Bu depo, Java ekosisteminde geliştirdiğim farklı seviyelerdeki projeleri ve temel programlama çalışmalarımı içermektedir.


### 🚀 01 Backend Systems
*Kütüphane yönetimi, sipariş sistemleri ve finans takip araçları gibi işlevsel backend projeleri.*

### 🛡️ 02 Security Tools
*Dosya şifreleme (AES), ağ tarayıcıları ve web güvenlik analiz araçları.*

### 📊 03 Data Utilities
*Veri analiz algoritmaları ve kayıpsız veri sıkıştırma (Run-Length Encoding) çalışmaları.*

### 💬 04 Network Chat
*Çok kanallı (Multi-threaded) soket programlama ile geliştirilmiş mesajlaşma sistemi.*

### 🚗 05 Smart Systems
*Akıllı otopark yönetimi ve şehir teknolojileri simülasyonları.*
